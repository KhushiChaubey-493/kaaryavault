# Kaaryavault – Task Management App

A simple and interactive Kanban-style task management application built using **HTML, CSS, and Vanilla JavaScript**.

Kaaryavault helps users organize their daily tasks into three different stages: To Do, In Progress, and Done. Users can create, delete, and move tasks between sections using Drag and Drop functionality.

## ✨ Features

- **Add Tasks:** Create tasks with a title and description.
- **Drag and Drop:** Move tasks between To Do, In Progress, and Done sections.
- **Delete Tasks:** Remove tasks with a smooth shrink-and-fade animation.
- **Dynamic Task Counter:** Automatically updates the task count of each section.
- **Local Storage:** Saves tasks and their statuses so they remain available after refreshing the browser.
- **Interactive UI:** Smooth hover effects, transitions, and animations.
- **Visual Drag Feedback:** Highlights sections while dragging tasks.

## 🛠️ Technologies Used

- HTML5 – Application structure
- CSS3 – Styling, transitions, and animations
- JavaScript (Vanilla JS) – Application logic and DOM manipulation
- Browser Local Storage – Persistent task storage

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/kaaryavault.git
   ```

2. Navigate to the project folder:

   ```bash
   cd kaaryavault
   ```

3. Open `index.html` in your browser.

That's it! You can now start managing your tasks with Kaaryavault.

## 💾 Data Storage

Kaaryavault uses the browser's Local Storage to save tasks and their current status. Your tasks remain saved even after refreshing the page, as long as the browser's stored data is not cleared.
